💻 Portfólio Pessoal — Thais Nascimento

Projeto desenvolvido como parte do Desafio 01 — Tire sua Ideia do Papel, do Bootcamp Desenvolvedor de Soluções Digitais da Kode Academy.

📌 Sobre o projeto

Este projeto consiste na criação de um portfólio pessoal responsivo, desenvolvido do zero com o objetivo de apresentar minha trajetória, conhecimentos, habilidades e projetos na área de tecnologia.

O portfólio foi desenvolvido utilizando HTML5 e CSS3, seguindo princípios de HTML semântico, acessibilidade, organização de código e responsividade.

🎯 Objetivos

O projeto tem como principais objetivos:

*Apresentar minha trajetória profissional e acadêmica;
*Demonstrar conhecimentos em desenvolvimento web;
*Apresentar projetos desenvolvidos durante minha formação;
*Praticar HTML5 semântico;
*Desenvolver uma interface responsiva;
*Aplicar conceitos básicos de acessibilidade;
*Utilizar Git e GitHub para controle de versão;
*Publicar o projeto utilizando GitHub Pages.

🤖 Uso consciente da Inteligência Artificial

A Inteligência Artificial foi utilizada como ferramenta de apoio ao desenvolvimento, conforme permitido pelo desafio.

A IA não foi utilizada com o objetivo de substituir o aprendizado ou simplesmente copiar um projeto pronto.

Ela foi utilizada principalmente para:

*Gerar ideias para a estrutura do portfólio;
*Auxiliar na organização das seções;
*Sugerir melhorias de acessibilidade;
*Explicar conceitos de HTML semântico;
*Auxiliar na organização do CSS;
*Identificar possíveis problemas no código;
*Sugerir melhorias de responsividade;
*Revisar a estrutura do projeto;
*Auxiliar na elaboração da documentação.

💬 Exemplos de prompts utilizados

1. Estrutura HTML

"Monte uma estrutura de portfólio utilizando HTML5 semântico, sem utilizar JavaScript, seguindo os requisitos de uma Landing Page."

Como ajudou:
A resposta foi utilizada como referência para organizar as principais seções do documento e compreender quais elementos semânticos poderiam ser utilizados.

2. Responsividade

"Crie um CSS responsivo para um portfólio utilizando Flexbox, CSS Grid e Media Queries, sem JavaScript."

Como ajudou:
A sugestão serviu como base para compreender a organização do layout responsivo e adaptar a página para diferentes tamanhos de tela.

3. Organização do CSS

"Explique como organizar um arquivo CSS de forma semântica, reutilizável e fácil de manter."

Como ajudou:
A resposta auxiliou na organização do arquivo CSS em seções, utilização de variáveis e criação de estilos reutilizáveis.
