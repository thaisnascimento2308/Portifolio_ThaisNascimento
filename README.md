# Portifolio_ThaisNascimento

Projeto de portfólio pessoal desenvolvido do zero com HTML5 e CSS3, com o objetivo de apresentar minha trajetória, habilidades, projetos e conhecimentos na área de tecnologia.

O projeto foi desenvolvido como parte do **Desafio 01 — Tire sua Ideia do Papel**, seguindo boas práticas de HTML semântico, acessibilidade, responsividade e organização de código.

A página é compatível com dispositivos móveis, tablets e desktops e foi desenvolvida sem JavaScript, utilizando exclusivamente HTML5 e CSS3.
